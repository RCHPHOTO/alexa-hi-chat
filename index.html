Hi Chat

Inteligencia artificial para tu Alexa.

¿Qué es Hi Chat?

Hi Chat es una skill para dispositivos compatibles con Amazon Alexa que permite hacer preguntas y recibir respuestas generadas mediante inteligencia artificial.

Cómo funciona

Para comenzar, decí "Alexa, abre Hi Chat". Durante esta versión de prueba, podés hacer consultas diciendo "pregunta" seguido de tu consulta.

Política de privacidad

Hi Chat procesa las preguntas que los usuarios realizan mediante Alexa para generar respuestas.

Las preguntas se transmiten desde Amazon Alexa al servicio de Hi Chat y se envían a la API de OpenAI para su procesamiento. Las preguntas pueden incluir información personal si el usuario decide proporcionarla.

No es necesario crear una cuenta adicional ni proporcionar datos de pago para utilizar esta versión de prueba.

No compartas contraseñas, información financiera ni otros datos sensibles durante tus consultas.

El tratamiento de información por parte de los proveedores también está sujeto a sus respectivas políticas: Amazon y OpenAI.

Esta política podrá actualizarse cuando se incorporen nuevas funcionalidades. Última actualización: 2 de noviembre de 2026.

Hi Chat · Proyecto independiente, no afiliado oficialmente a Amazon ni a OpenAI.
